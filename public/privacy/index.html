개인정보처리방침

YeongduMusic가 Google 계정과 Drive 데이터에 접근하고 이를 이용하는 방식을 안내합니다.

실제 앱의 인증 정보 저장, 서버 전송 여부 및 개발자 연락처가 아직 확인되지 않았습니다. Google OAuth 검증을 신청하기 전에 이 내용을 반드시 확정해 주세요.

1. 개인정보처리방침 개요

YeongduMusic(이하 “앱”)는 Google Drive에 저장된 음악을 탐색·재생하고, 사용자가 선택한 음악을 오프라인으로 다운로드할 수 있도록 돕는 개인 음악 플레이어입니다.

이 방침은 앱이 Google 계정과 Google Drive 관련 정보를 어떻게 접근·이용·보관·공유하는지 안내합니다. 운영자 연락처는 이 문서 마지막에 기재합니다.

2. 접근하는 정보

이용자가 Google 계정 연동에 동의하는 경우, 앱은 Google 동의 화면에 표시된 접근 범위(스코프) 안에서 다음 정보를 처리할 수 있습니다.

  • 인증 관련 정보: Google OAuth 인증 결과 및 서비스 접근에 필요한 토큰. Google 프로필·이메일 정보는 해당 권한을 요청하고 허용받은 경우에만 해당합니다.
  • Drive 음악 파일 정보: 앱에 허용된 범위의 파일 이름, 식별자, 형식, 크기, 폴더·메타데이터 및 앨범아트 등 재생에 필요한 정보.
  • 음악 파일 내용: 이용자가 재생하거나 오프라인 다운로드하도록 선택한 파일의 데이터.
  • 기기 내 데이터: 재생을 위한 캐시, 앱 환경설정, 선택한 오프라인 다운로드 파일 등.

앱에 승인한 접근 권한의 정확한 범위는 Google 계정 연결 화면에서 확인할 수 있습니다.

3. 이용 목적

앱은 위 정보를 Google 계정 연결, 음악 파일 탐색 및 목록 표시, 음악 스트리밍 재생, 사용자가 선택한 파일의 오프라인 보관·재생, 오류 대응 및 서비스 보안을 위해 필요한 범위에서 이용합니다.

Google Drive의 음악 파일에 접근하는 목적은 사용자가 요청한 음악 관련 기능 제공입니다. 사용자 동의 없이 Google Drive의 파일을 공개하거나 다른 사용자와 공유하는 기능을 전제로 하지 않습니다.

4. 저장 및 보관 기간

오프라인 다운로드를 선택한 음악 파일은 해당 기능을 제공하기 위해 이용자 기기에 저장될 수 있습니다. Google 인증 정보와 음악 목록·재생 정보 또한 앱이 동작하는 동안 기기에 보관될 수 있습니다.

이용자가 Google 계정의 앱 접근 권한을 철회하면 앱은 해당 계정에 대한 새 API 요청 권한을 잃을 수 있습니다. 다만 이미 기기에 저장된 음악 파일이나 캐시가 함께 삭제되는지는 앱의 실제 삭제 기능에 따라 달라집니다.

공개 전 확인 항목:

인증 토큰의 실제 저장 위치 및 방식, 서버 전송 유무, 캐시 보존 기간, 로그아웃·연결 해제·앱 삭제 시 데이터가 어떻게 삭제되는지를 코드에서 확인한 후 이 조항을 확정해야 합니다.

5. 외부 서비스 이용 및 정보 제공

Google 계정 인증과 Google Drive 파일 접근을 위해 Google의 인증 및 Drive API가 사용됩니다. 이때 Google에 전송되는 요청은 Google의 서비스 정책과 이용자의 승인 범위에 따릅니다.

앱 운영자가 별도로 운영하는 서버, 로그 수집 도구, 오류 분석 SDK, 광고·분석 도구 등을 사용하는 경우 서비스 이름과 전달되는 데이터의 종류·목적을 이 조항에 명시해야 합니다.

공개 전 확인 항목:

현재 초안에는 Google API 이외의 제3자 서비스나 개발자 서버에 대한 전송 여부가 확정되어 있지 않습니다. 실제 앱 아키텍처를 확인해 “전송하지 않음” 또는 각 서비스별 처리 내역으로 교체해야 합니다.

6. Google API 사용자 데이터 사용

Google API를 통해 얻은 사용자 데이터는 사용자가 요청한 앱 기능 제공에 필요한 범위에서만 이용하도록 설계해야 합니다. Google API 사용자 데이터를 맞춤형 광고 제공, 데이터 브로커에게 판매 또는 관련 없는 용도로 사용하는 것은 허용되지 않습니다.

앱의 Google 데이터 접근·이전·보관·이용은 Google API Services User Data Policy의 Limited Use 요구사항을 포함한 관련 정책을 준수해야 합니다. 실제 구현 또한 본 방침에 기재한 내용과 일치해야 합니다.

7. 이용자의 선택 및 연결 해제

이용자는 앱에서 제공하는 계정 연결 해제 또는 관련 데이터 삭제 기능을 이용할 수 있으며, Google 계정의 서드 파티 앱 연결 관리에서 YeongduMusic의 접근 권한을 철회할 수 있습니다.

오프라인 저장 파일을 포함한 기기 데이터 삭제 방법은 앱에 제공된 기능에 따라 달라집니다. 연결 해제만으로 모든 로컬 파일이 자동 삭제된다고 보장하지 않습니다.

8. 보안과 변경 사항

앱은 정보에 대한 불필요한 접근을 줄이기 위해 Google OAuth 승인 범위를 최소화하고, 인증 정보의 안전한 저장과 접근 제한을 고려해야 합니다. 구체적인 보안 조치는 실제 구현에 맞춰 안내해야 합니다.

데이터 처리 방식이나 관련 기능이 변경되는 경우 이 개인정보처리방침도 갱신하며, 중요한 변경 사항은 앱 또는 홈페이지에서 알릴 수 있습니다.
